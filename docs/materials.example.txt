# Material table — pass to the converter via CAD_MATERIALS=materials.example.txt
# (later: --materials on the CLI). Plain text, first matching rule wins.
#
#   part <pattern> = <material>     glob over the part name/number
#   color RRGGBB   = <material>     exact face colour
#   default        = <material>     surfaces with no other evidence
#
# Any rule may end in a colour: `= <material> #RRGGBB`. That is the only thing
# here that replaces the colour the CAD file states — everything else changes
# how a surface is finished and leaves its colour alone. Use it for a product
# that is not delivered in the colour it was modelled in, a casting drawn grey
# and shipped black, which no amount of reading the file will reveal. A
# material named `AISI 304` or `1.4301` keeps its name: only a `#` counts.
#
# Material names are classified by keyword — English and Turkish trade names
# and common designations all work: "AISI 304", "Paslanmaz Çelik", "6061-T6",
# "EPDM", "POM", "Pirinç MS58", "Dökme Demir GG25", "Toz Boya RAL 5010", ...
# A name that classifies as nothing keeps its name and is shaded by its colour.
#
# Without a table, colours are inferred: neutral greys read as machined metal
# (bright → aluminium, mid → steel, dark → cast iron, near-black → rubber) and
# saturated colours as paint. Disable with CAD_NO_INFER=1.
